# MSN Brock — Client Portal Simulation

A polished front-end prototype for a fictional investment/client dashboard.

## Safety boundaries
- All balances, payment records, withdrawals, KYC states and market prices are simulated.
- Trading is paper trading only.
- No real bank transfer, brokerage order, identity verification, or financial transaction is implemented.
- KYC file controls are UI mocks and do not upload documents.
- Market news is placeholder content and is not represented as live financial news.

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

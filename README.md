# WealthCore Demo — GitHub Pages

A browser-based educational paper-trading / portfolio simulation adapted from the supplied HTML.

## Important safety notice
This is a **fictional demo project only**. All client balances, prices, IPO information, returns, reference IDs and payout statuses are sample data. It does not connect to a broker, exchange, bank, UPI, RTGS, SEBI, registrar or payment processor. No money is transferred and no return is guaranteed.

Do not enter real bank account numbers, IFSC codes, Aadhaar, PAN, UPI IDs, passwords or other personal information. Demo state is stored in browser local storage and is not secure authentication or a server database.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Use the **View 14 Client & Admin Logins** helper on the login page to inspect sample demo credentials.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Project limitations
- Static front-end only; no backend or secure user authentication.
- Browser local storage can be edited or cleared by users.
- Market figures are hard-coded sample values, not live market feeds.
- Orders, deposits, IPO applications and payout requests are simulations only.

# Market Terminal — Demo Paper Trading

A self-contained static demo website. No build step, framework, API key, backend, or external dependency is required.

## Run
Open `index.html` in a modern browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish.
